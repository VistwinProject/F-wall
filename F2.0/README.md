# F 2.0 AI 大腦控制塔重製版

此版本重新撰寫三端 UI、同步狀態管理、WebGL 發光引擎與 Node 伺服器。
初代僅作為畫面、固定投影座標、設備 ID、示範內容及圖片素材的依據。
先前誤複製的三份專案已移到 `_initial-copy/`，新程式不匯入其中任何程式。

## 啟動與預覽

在此資料夾執行 `npm install`，再執行 `npm start`。

- 桌面：<http://localhost:6273/table>
- 牆面：<http://localhost:6274/wall>
- iPad：<http://localhost:6275/ipad>

三個 HTTP 入口共享同一個伺服器記憶體狀態，WebSocket 使用各自 HTTP 入口。
這一組 6273–6275 埠與先前初代預覽的 5173–5175 分開。
在同網路的其他裝置預覽時，以此電腦的區域網路 IP 取代 localhost。

## 操作

- iPad 點擊歡迎頁開始，桌面同時淡出歡迎頁。
- 左下「替代 NFC 卡片」可逐張放上／拿走，三端收到伺服器廣播後才更新。
- 鍵盤 1–9 切換卡片，A 全放、0 全拿、E 開啟版面校正。
- 「自動展示」每 2.6 秒放上一張，九張停留 5 秒，再逐張移除。手動操作會停止展示。
- 桌面資料每 8 秒輪播；新放上的家電立即獲得焦點。
- iPad 點擊已連接的卡片或節點可看資料和連動關係。
- 九台全連接顯示完成浮層；「檢視連動圖」可回到完整圖譜。
- 重置會清除卡片狀態並讓桌面、iPad 回到歡迎頁。
- 斷線保留最後畫面，控制不會在本地搶先執行；重連取得完整快照。

## 程式結構

- `src/devices.js`：共享設備資料、九個固定 ID、投影幾何、關聯與時序。
- `src/session.js`：共用 WebSocket 連線、重連及 slot → device 狀態 reducer。
- `src/geometry.js`：新寫的圓環、圓角路徑及固定牆面走線。
- `src/glow.js`：三端幾何與 NFC 狀態接到範例發光引擎的轉接層。
- `src/glow-reference/`：沿用「發光特效-範例」的 shaders、ribbon、stage、scene 與 params，五個檔案未修改。
- `src/app.js`：三端畫面、數據面板、NFC 預覽操作與版面校正。
- `src/style.css`：三端共用材質與依初代參照重建的排版。
- `server/index.mjs`：權威狀態、廣播、快照、展示排程與 NFC 適配。
- `public/`：原始家電圖片與俯視平面图，僅素材沿用。

## 投影與校正

牆面使用 1920 × 1080 等比置中，九個家電框、中樞和電視框均為純黑。
預覽會疊上原始家電圖片表示實體模型；正式投影使用 `/wall?projection` 隱藏圖片與模擬面板。

- `?nofx`：停用 WebGL，保留 SVG 基礎連線、文字、圖片及面板。
- `?noglass`：使用不透明面板。
- `?all`：牆面局部預覽全部點亮，不改動伺服器狀態。
- `?fps`：顯示 FPS 與最長幀時間。
- `?edit`：開啟編輯面板；牆面拖曳資料面板，iPad 拖曳節點／卡片／中樞，桌面拖曳左側面板。
- `?ws=host:port`：連接其他狀態伺服器，也接受完整 ws/wss URL。

校正存於各入口的 localStorage，角落持續顯示「已套用編輯值」，可匯出 JSON 或恢復預設。
此版不提供十一個實體投影遮罩的任意拖曳，避免偏離原始安裝座標。

## 實體 NFC

先安裝 PC/SC 與 `npm install nfc-pcsc`，依現場讀卡機名稱建立 `server/reader-map.json`，
再執行 `npm run live`。此模式不啟用模擬卡片，也不允許牆面送控制訊息。
已登記的五張 UID 存於 `server/uid-map.json`；另外四台需由現場登記真實 UID。
保留原始六種事件的欄位，`tag-remove` 只有 `slot_index`；新增 snapshot 事件用於重連恢復。

目前所有用量、感測值、趨勢與維養排程都是展示資料，未串接 Welltek API。
硬體模式需要現場 ACR122U 實機測試；瀏覽器預覽不能代替硬體驗收。

## 與初代的實作差異

2026-09-09 起，三端的框線、圓環、關聯線與傳輸光束改用新增範例的 UnrealBloomPass 後製及原始參數。
範例的光束材質已含底光，因此轉接層會排除原本同路徑的額外底光，避免疊加過亮。
動畫保留底光呼吸、穩定亮度的資料彗星與淡入淡出；素材、規定座標與主要內容沿用。
新版不會因 HTTPS 自動改成各分頁獨立的假資料；跨裝置同步必須能連線至同一伺服器。
