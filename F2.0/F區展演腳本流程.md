# F 區｜AI 大腦控制塔・展演腳本流程

整理日期：2026/09/15  
展期：2026/10/11–2027/04/30  
畫面資料基準日：2026/10/11  
版本依據：目前 F 2.0 程式與已保存版本 `8a0a2a7`。

> 本文件整理目前已實作的展演流程。標為「建議口白」的文字供現場導覽使用，並非新增的系統配音。既有語音與新版畫面的差異列於文末，本次僅整理文件。

## 1. 展演主軸

觀眾透過放置家電感應物件，逐步建立一個與 AI 大腦連結的家。桌面顯示當下狀態，牆面呈現設備與系統連動，iPad 提供累積用電、運轉時數、設備壽命及維護保養資訊。最後九台設備全部串聯，收束到「懂你、照顧你，持續進化的生活夥伴」。

完整流程：

**首頁待機 → iPad 播放前導 → 再次點選開始體驗 → 逐一放置家電 → 三端同步回應與家電語音 → iPad 深入查看 → 九台全屋串聯 → 結尾語音 → 檢視連動圖 → 移除物件並重置。**

### 三端分工

| 介面 | 展演功能 | 觀眾看到／聽到的內容 |
| --- | --- | --- |
| Table 桌面投影 | 感應回饋、資訊摘要、聲音主輸出 | ANLB 光束首頁、AI 語音球、感應位置、家電狀態、用電趨勢、維護保養計畫；播放前導、家電及結尾語音 |
| Wall 牆面投影 | 空間中的設備與連動展示 | 對應實體位置的設備區塊、運作效果與連線；投影配置含九台設備、AI 中樞及電視區域 |
| iPad | 開始體驗、資料探索及重置 | 首頁、全屋平面連動圖、已放置數量、家電詳細資訊、完成提示 |

**聲音由 Table 統一輸出。** iPad 負責發送前導及結尾播放要求，並不是聲音播放端。

## 2. 現場開演前準備

1. 開啟 Table、Wall、iPad 三個介面，確認連線正常。
2. 在 Table 點選「啟用 Table 語音」，確認喇叭音量與輸出位置。
3. 移除所有感應物件，按 iPad「重置」，確認回到首頁、設備數量歸零。
4. 確認九種家電物件可分別辨識，並測試牆面設備位置與感應位置對應。
5. 正式投影使用已校正的畫面配置；Wall 可使用 `/wall?projection` 隱藏示意照片與模擬操作工具。

### 本機三端入口

| 端點 | 同一主機上的網址 |
| --- | --- |
| Table | http://localhost:6273/table |
| Wall | http://localhost:6274/wall |
| iPad | http://localhost:6275/ipad |

iPad 若為另一台實體裝置，網址中的 `localhost` 要換成展演主機的區網 IP。三端必須連至同一展演服務。

工作人員啟動指令：在 `F2.0` 目錄執行 `npm start` 為模擬模式；`npm run live` 為實體 NFC 模式。實體模式需先完成讀卡機及卡片對應設定。

## 3. 主流程與現場操作腳本

### 第一幕｜首頁待機與邀請

**畫面**

- Table 與 iPad 顯示「AI 大腦控制塔」首頁，以深藍底、青藍光束呼應展覽主視覺。
- iPad 提示「點選任意位置播放前導語音」。
- Wall 維持投影空間配置，等待設備加入。

**建議口白**

> 這裡是家的 AI 大腦控制塔。請先點一下 iPad，聽聽這位無形管家如何照顧我們的家。

**操作**：觀眾點選 iPad 首頁一次，Table 開始播放前導。

### 第二幕｜前導語音

**時長**：約 37.46 秒。

**前導內容整理稿**（依現有音檔自動逐字稿修正明顯錯字與標點；正式逐字定稿仍以原音檔為準）：

> 隱藏在牆後的無形神經，早已將家裡所有的裝置串聯在一起。  
> 它就像一位永遠不會退休、最懂這棟房子的無形管家。  
> 它不只看得到資料，更能為您預判問題。  
> 在裝置真正發生異常或老化之前，它就已經早一步妥善打理好一切。  
> 未來，您不需要去研究複雜的系統。  
> 只需透過手機，就能一目瞭然看懂家的健康與維養報告。  
> 家，終於成為懂你、照顧你，持續進化的生活夥伴。

**操作與轉場**

- 播放中，iPad 顯示「前導語音播放中 · 點選可略過」。
- 播放完畢後改為「點選任意位置開始體驗」。
- **需再點一次 iPad，才會正式進入互動主畫面。** 播放結束不會自動開始。
- 若要略過，播放中點一下停止前導，再點一下進入體驗。

### 第三幕｜開始體驗、等待第一台家電

**操作**：在前導完成後點選 iPad，進入主畫面。

| Table | Wall | iPad |
| --- | --- | --- |
| 首頁淡出，出現 AI 語音球與「感應待機中」資訊面板 | 等待設備啟用 | 顯示全屋平面圖、AI 大腦及「已放置 0 / 9」 |

Table 待機面板底部顯示：

> 2026/10/11 · 延伸圖表及保養計畫為模擬展示

**建議口白**

> 請選擇一台家電，放到感應位置上。您會看到它連上家的 AI 大腦，也能進一步查看它的使用狀態與保養資訊。

### 第四幕｜放置家電、三端同步回應

每放入一個可辨識的家電物件，依序發生：

1. 系統辨識家電身分，加入目前連線的設備。
2. Table 顯示感應回饋、家電圖示與通往 AI 語音球的連線，資訊面板切換至該家電。
3. Table 面板中的數值、圖表與圓環跑動進場，維護保養項目依序出現。
4. Wall 啟用對應設備區域與連動效果。
5. iPad 點亮對應設備、更新放置數量，顯示已啟用設備間的關係。
6. 約 0.5 秒後，Table 播放該家電語音，語音球隨聲音反應；家電字幕跟隨播放。

**操作節奏**

- 系統允許自由順序，沒有強制的第一台或最後一台。
- 導覽時建議每台語音播完，再加入下一台；每台可預留約 15–20 秒。
- 新物件加入會切換至新語音，**不會排隊等待上一段播完**。
- 移除正在發聲的家電物件，會停止該段語音。
- 同時有兩台以上設備時，Table 資訊面板約每 8 秒輪播一次；新加入的設備優先顯示。
- 家電圖示保留於感應／連線區，資訊面板內不再放家電 icon。

### 第五幕｜透過 iPad 深入查看

**操作**：點選 iPad 上已啟用的家電，打開詳細資訊。

| 分頁 | 展示內容 | 建議解說重點 |
| --- | --- | --- |
| 總覽 | 家電圖像、業主指定數值、使用與壽命指標 | 不只是知道開或關，也能了解設備目前的健康與使用狀況 |
| 用量趨勢 | 累積用電、累積時數及各設備適用的圖表 | 讓平常看不見的使用紀錄變得容易理解 |
| 維護保養 | 保養排程、待辦項目與近期保養紀錄 | 把保養時間與工作內容整理清楚，減少遺忘 |

**建議口白**

> 點進家電，就能看到累積使用情形、用量趨勢，以及接下來要做的保養。這裡以開展日為資料基準，延伸圖表與紀錄是展示用的模擬內容。

點未啟用的家電不會直接進入詳細資料，需先放上對應物件。查看後關閉詳細頁，回到全屋連動圖，再繼續加入家電。

### 第六幕｜九台全部串聯

**觸發條件**：九種不同家電均保持在感應位置，最後加入的家電語音播放完畢，再等待約 2 秒。

**呈現**

- iPad 顯示完成提示：
  - `ALL SYSTEMS LINKED`
  - `全屋家電已串聯至 AI 大腦`
  - `AI 正在學習你的生活方式，將自動調節出最舒適的居家情境。`
- Table 播放結尾語音，語音球呈現完成串聯的動態。
- Wall 保持全屋設備啟用的展演狀態。

**結尾既有字幕稿**（約 8.45 秒）：

> 全屋家電已連接到 AI 大腦，系統正在學習您的生活方式，為您調節最舒適的居家環境。

**建議口白**

> 當所有設備串聯起來，家就能從個別設備的資訊，走向整體生活的照顧。您也可以再點開家電，看看不同設備之間的關係。

### 第七幕｜自由探索與下一輪

1. 點 iPad「檢視連動圖」，關閉完成提示，保留九台設備的連線狀態。
2. 觀眾可繼續查看詳細資訊，或拿走家電觀察連線取消。
3. 少於九台時，完成狀態取消；若結尾仍在播放，也會停止。
4. 結束本輪時，先移除全部實體物件，再按「重置」。
5. 三端清除本輪狀態、停止語音；Table 與 iPad 回到首頁，準備下一組觀眾。

**注意**：「全部拿走」只清除設備，不等同完整重置。要重新播放前導並回到首頁，使用「重置」。實體物件應先拿走，下一輪再放上，讓讀卡機產生新的感應事件。

## 7. 模擬操作與現場備援

| 操作 | 目前行為 | 使用時機 |
| --- | --- | --- |
| 1–9 或「替代 NFC 卡片」 | 切換指定家電放上／拿走 | 無實體讀卡機時逐台演練 |
| A／全部放上 | 一次放上九台，抑制家電與結尾語音 | 快速檢查全屋畫面，不用於完整配音演出 |
| 0／全部拿走 | 清除設備並停止語音，維持目前體驗階段 | 檢查移除效果 |
| 自動展示 | 約每 2.6 秒加一台，全放上後停留約 5 秒，再逐台移除、循環 | 視覺巡演；加入太快會打斷家電語音 |
| 重置 | 停止展示、停止語音、清除設備並結束本輪 | 回首頁，準備下一場 |

### 常見狀況

- **沒有語音**：先在 Table 啟用語音，確認音量；前導失敗可由 iPad 重試。家電若顯示「點此播放家電語音」，點選後播放。
- **感應後沒反應**：確認卡片已對應至九種設備之一、讀卡機與服務連線正常；演練可改用模擬卡片。
- **九台放滿但沒有結尾**：確認是九種不同設備，且最後一台語音已正常播完；現行結尾等待該播放完成事件。處理語音後，可拿起最後一台再放回。
- **重新載入 Table 後沒有重播已放上的家電**：現有卡片狀態還原不會自動補播；拿起再放上才會產生新的播放事件。
- **公網展示版與現場不同步**：GitHub Pages 版以同一瀏覽器環境的本機狀態同步，不能取代現場跨裝置的 NFC 服務。正式硬體展演使用同一主機服務連線。

## 8. 資料口徑與待校稿事項

### 已採用的資料口徑

- Table／iPad 統一以 **2026/10/11** 為模擬資料基準，不會隨真實日期每日自動累積。
- 業主提供的設備數據為主要依據；延伸用電、時數、趨勢、歷史與保養排程包含模擬內容。
- 10 月資料只統計至 11 日，不能直接與完整月份判定增減；智慧插座下降 8% 的延伸比較採上月同期口徑。
- 圖中感測數值與連動關係屬展示情境，並非現場即時感測或真實設備控制結果。
