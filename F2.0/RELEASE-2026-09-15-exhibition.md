# F 2.0 展覽確認版 — 2026/09/15

展示基準日：2026/10/11；展期：2026/10/11–2027/04/30。

## 本版確認項目

- Table 與 iPad 九項家電文案依業主資料對齊，共用一致的展示數據。
- iPad 詳細頁增加總覽、用量趨勢、維護保養分頁；含累積用電、時數／次數、圖表及保養紀錄。
- Table 加入用電柱狀圖、維養計畫及進場動畫；圓形圖移至最上方資訊框右側，資訊面板內不再顯示家電 icon。
- 圖表註記留在用電趨勢框內底部；修正 iPad 詳細頁捲動時的多餘玻璃邊框。
- 首頁採展覽主視覺風格：深藍漸層、筆直冰藍斜光束、下方弧形光帶。
- 光束構圖垂直壓縮 20% 並置中；iPad 額外放大背景 20%，呈現超出畫面的裁切感。
- 原始業主數值作為開展日模擬快照；延伸歷史及維養計畫清楚標示為展示資料。
- 修正 GitHub Pages 的背景素材路徑，維持三端公開展示版可用。

## 驗證

- 九項設備指定數值、圖表加總、時數上限、維養日期通過自動檢查。
- Table 與 iPad 首頁、資訊面板與詳細頁已在本機瀏覽器視覺檢查。
- 三端 GitHub Pages 建置與背景素材相對路徑檢查。

## 發布範圍

沿用 `vistwinproject/F-table`、`F-Ipad`、`F-wall` 的 `v2.0` 分支發布公開模擬版。
不包含本機讀卡機／UID 對照、備份、未納入專案的語音原始稿及素材壓縮檔。
