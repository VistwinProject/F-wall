寶鋪 F 區「AI 大腦控制塔」牆面投影 — 可攜版
=================================================

【怎麼用】
把整個 portable 資料夾複製到任何一台 Windows (64 位元) 電腦，
雙擊下面其中一個檔案即可，不用安裝任何東西：

  ● 啟動牆面.bat   ← 正式投影用
       會連到桌面的 NFC 伺服器 (ws://localhost:8787)，
       桌上放卡片時，牆上對應的那條線才會亮起、流向中樞。
       （所以單獨開這個、桌面沒開時，畫面是暗的、等待觸發，這是正常的。）

  ● 測試-全部亮.bat ← 想直接看畫面長怎樣用
       不需要桌面伺服器，9 條線會全部亮起，用來檢查投影畫面。

開啟後會用 Chrome 全螢幕 (kiosk) 顯示；找不到 Chrome 會自動改用 Edge。

【怎麼關】
在投影畫面上按 Alt + F4 關閉瀏覽器，伺服器會自動一起關掉。

【完全免安裝】
這個資料夾已經內建好執行環境 (runtime\node.exe)，
換電腦只要複製整包過去就能用，不必裝 Node.js、不必連網路。

【裡面有什麼】
  啟動牆面.bat / 測試-全部亮.bat … 雙擊入口
  _run.bat                          … 內部共用腳本（不用理它）
  server.mjs                        … 本機小型網頁伺服器
  app\                              … 已打包好的牆面畫面 (build)
  runtime\node.exe                  … 內建執行環境

【要更新畫面時】
若之後改了原始碼，重新 build 後把新的 dist\ 內容覆蓋到 app\ 即可，
其餘檔案都不用動。

埠號固定 5174（被佔用會啟動失敗，請先關掉佔用的程式）。
